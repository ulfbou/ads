# Accountable Decision System

A local, evidence-bounded .NET 10 system for recording observations, decisions, outcomes, reflections, and non-authoritative proposals in an immutable JSONL ledger.

This repository currently contains the deterministic WP17-01 build foundation. Runtime semantics are introduced only by subsequent authorized work packages.
